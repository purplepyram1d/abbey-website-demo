# Coastal Calm Organizing & Concierge

A responsive static landing page for an organizing, unpacking, and lifestyle concierge business serving Florida's Emerald Coast.

## Preview locally

The site has no build step or third-party dependencies. Open `index.html` directly, or run any simple local static server from this folder.

## Publishing

This project is ready for GitHub Pages. Push the contents of this folder to the target repository, then enable Pages from the repository's default branch and root folder.
